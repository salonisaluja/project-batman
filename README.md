# WAYNE ENTERPRISES | BATCOMPUTER v3.0

A romantic, Batman-themed interactive website built with HTML, CSS, and JavaScript.

## Features

✨ **Loading Screen** - Wayne Enterprises branded loading animation
🎬 **Hero Section** - Typewriter animation with access button
📋 **Mission File** - Sweet mission briefing
📊 **Hero Analysis** - Stats about Batman (with interactive hover effects)
🎵 **Music Player** - Toggle background music
⌨️ **Keyboard Controls** - Navigate with arrow keys or spacebar, toggle music with 'M'

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/salonisaluja/project-batman.git
   cd project-batman
   ```

2. Open `index.html` in your browser or use a local server:
   ```bash
   python -m http.server 8000
   # or
   npx http-server
   ```

3. Visit `http://localhost:8000` in your browser

## File Structure

```

├── assets/         # Audio and media files
│   └── rewrite-the-stars.mp3
└── README.md       # This file
```

## Customization

- **Change the text**: Edit the text in `index.html`
- **Adjust colors**: Modify the hex colors in `style.css` (currently using `#00ff88` and `#00ccff`)
- **Add your music**: Replace the audio file in `assets/rewrite-the-stars.mp3`
- **Add more sections**: Create new `<section>` elements and they'll appear when you click "ACCESS FILES"

## Browser Support

Works on all modern browsers (Chrome, Firefox, Safari, Edge)
